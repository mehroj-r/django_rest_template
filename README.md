# Cookiecutter Template

Generate a new project from this template:

```bash
cookiecutter .
```

Optional (recommended) explicit output directory:

```bash
cookiecutter . -o ./cookiecutter-output
```

Key naming prompts in this first iteration:

- `project_name`
- `project_slug`
- `distribution_name`
- `docker_name_prefix`
- `github_username`
