# 🚀 Django Boilerplate

A central repository hosting multiple production-ready Django REST API templates. Each template is maintained on a separate branch with its own documentation and setup guide.

## 🎯 Overview

This repository serves as a **central hub** for various Django REST API boilerplate templates. Each branch contains a complete, production-ready template tailored for specific use cases:

- ✅ **Multiple Templates** - Choose the template that best fits your project
- ✅ **Self-Contained** - Each template has its own documentation and setup
- ✅ **Production-Ready** - Following Django and DRF best practices
- ✅ **Well-Documented** - Each template includes comprehensive guides
- ✅ **Active Development** - Templates are maintained and updated regularly

---
## 🚀 How to Use

### Step 1: Clone the Repository
```bash
git clone https://github.com/mehroj-r/django_boilerplate.git
cd django_boilerplate
```

### Step 2: Choose Your Template
```bash
# List all available branches
git branch -r

# Switch to your preferred template
git checkout drf
```

### Step 3: Follow Template Documentation
Each template branch contains a complete README with:
- Detailed setup instructions
- Project structure explanation
- Configuration guide
- Environment variables
- Development workflow
- API documentation
- Deployment instructions
- Troubleshooting guide

Simply follow the README in your chosen branch.

### Example: Getting Started with DRF
```bash
git clone https://github.com/mehroj-r/django_boilerplate.git
cd django_boilerplate
git checkout drf

# Now follow the README in the drf branch for:
# - Prerequisites
# - Installation
# - Configuration
# - Running the development server
# - API usage
```

## 💡 Tips

1. **Each branch is independent** - Clone once, but you can switch branches to explore different templates
2. **Check branch READMEs** - Each branch has comprehensive documentation tailored to that template
3. **Same repository, different projects** - Each branch feels like a different project with its own setup
4. **Start with DRF** - If you're unsure, the DRF template is a great starting point

## 🤝 Contributing

To contribute to a specific template:

1. Switch to the template branch: `git checkout drf`
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Follow the CONTRIBUTING guide in that branch's README
5. Submit a pull request

For contributions to this central hub, create issues or discussions about template ideas.
